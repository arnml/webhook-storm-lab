# Lab requirements

- Demonstrate retry amplification and buffered, bounded processing of a webhook burst.
- Provide a locally runnable example and tests; verify webhook signatures and validate input.
- Define optional AWS infrastructure using TypeScript and Terraform: HTTP ingress, durable queue, bounded worker, dead-letter queue, and basic observability.
- Explain operational tradeoffs, duplicate delivery, and production gaps without claiming the example is production-ready.
